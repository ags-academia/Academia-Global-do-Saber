# Academia-Global-do-Saber
Academia Global do Saber é um centro de explicação localizado na Cidade de Inhambane, presta serviços de reforço escolar a partir da 7ª à 12ª classes, nas disciplinas de ciências como Matemática, Física, Química, Desenho e Biologia. O Co-Autor da desta iniciativa é Alexandre Gomes da Silva.
